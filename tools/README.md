# tools — исходники и инструменты

- `validate_pack.py` — проверка пакета перед публикацией: `python3 tools/validate_pack.py packs/pack-003.json`.
- `content/banks.py`, `content/gen.py` — банки предложений и генератор pack-002 (образец для следующих пакетов; пути внутри рассчитаны на /home/claude).
- `app.js`, `app.src.html`, `build/build.py`, `level-v1.json` — исходники приложения. Для публикации нового пакета пересобирать приложение НЕ нужно: достаточно положить JSON в `packs/` и дописать `packs/index.json`.

## Хранение ответов и файл разбора (с 31.10.2026)
- Каждый неверный ответ сохраняется в `progress[id].wrong` и уходит в экспорт (`mistakes`). Уже разобранные помечены `reviewed: true`; в `summary` есть `reviewedUpTo` и `mistakesOpen`.
- Ответ удаляется с устройства только если он **разобран Claude** (дата ≤ `upTo` последнего файла разбора) **и ему больше 7 дней**. Неразобранные не удаляются никогда.
- После каждого анализа экспорта Claude публикует `packs/review-ГГГГ-ММ-ДД.json` и добавляет его в `packs/index.json` → `results`:
```json
{ "type": "review", "id": "review-2026-11-05", "date": "2026-11-05", "upTo": "2026-11-05", "summary": "кратко по-русски" }
```
`upTo` — дата самой поздней ошибки из разобранного экспорта.

## Задание: разбор, правило, продолжение (с 31.10.2026)
- Разбор ответа: «Ваш ответ» и «Правильно» — целые предложения (в «вписать форму» и «выбор» слово подставляется в предложение), неверное красным, изменённое зелёным. Ниже — `why` вопроса (если есть), перевод (`explain`), кнопка «Правило».
- «Правило» доступно только после ответа и открывает шторку. Какой урок показать: поле `rule` у вопроса (id урока, например `p3-d2-g1`) → иначе урок того же дня и раздела → для заданий-повторений («Повторение», «Итог», «Смешанная», «вперемешку»…) вкладки со всеми уроками раздела до этого дня.
- **В новых пакетах у каждого вопроса упражнений указывать `rule` и `why`** (1 строка по-русски: почему так).
- Состояние задания сохраняется после каждого ответа в `S.inProgress[id]` (вопрос, ответы, ошибки, время, черновик письма); при возврате открывается тот же вопрос или разбор. В экспорт идут `inProgress` и ошибки недоделанных заданий (`unfinished: true`).

## Открытые ответы и оценки Claude (с 31.10.2026)
- **Перевод с русского не проверяется автоматически.** Ответ сохраняется в `progress[id].open = [{i, prompt, answer, ref, alt, voice, date}]` (для недоделанных — в `inProgress[id].open`) и уходит в экспорт как `openAnswers` (только ещё не оценённые). Автобалл задания (`score/total`) считается только по остальным вопросам; у чисто переводных заданий `total` нет.
- Письменные задания (`write`) — как раньше: `progress[id].answer`.
- **Оценки Claude** кладутся в тот же файл разбора `type: "review"` полем `verdicts` (можно и в файле без `upTo`, если нечего отмечать как разобранное — тогда добавить `upTo` = дата экспорта):
```json
{ "type": "review", "id": "review-2026-11-05", "date": "2026-11-05", "upTo": "2026-11-05", "summary": "…",
  "verdicts": [
    { "id": "v-p2-d1-g7-0", "task": "p2-d1-g7", "i": 0, "verdict": "ok" },
    { "id": "v-p2-d1-g7-1", "task": "p2-d1-g7", "i": 1, "verdict": "wrong", "correct": "I did the dishes.", "comment": "do the dishes — устойчивое сочетание" },
    { "id": "v-p2-d1-g7-2", "task": "p2-d1-g7", "i": 2, "verdict": "almost", "correct": "…", "comment": "…" },
    { "id": "v-p2-d1-g10-text", "task": "p2-d1-g10", "level": "B1", "comment": "общий отзыв", "fixes": [ { "from": "…", "to": "…", "why": "…" } ] }
  ] }
```
  `verdict`: `ok` | `almost` | `wrong`. Для текста (`write`) поле `i` не указывается — это оценка всего текста (`level`, `comment`, `fixes`).
- Приложение показывает оценки внутри пройденного задания и на экране «Сегодня» в карточке «Проверка Claude» (точность переводов, сколько ждут проверки).
- **Задания прошлых дней** (`progress.at` < сегодня) открываются только для просмотра результата; пройти заново можно только в день выполнения.
