# Мой учебный план

Личное приложение для учёбы (PWA): iPhone и Mac, работает офлайн, данные хранятся на устройстве.

## Что в папке
- `index.html` — приложение.
- `manifest.webmanifest`, `icons/` — название и иконка для экрана «Домой».
- `sw.js` — офлайн-режим.
- `packs/` — пакеты заданий. `packs/index.json` — список пакетов; новые пакеты Claude добавляет сюда, приложение загружает их само.

## Установка
**iPhone:** откройте адрес сайта в Safari → «Поделиться» → «На экран Домой».
**Mac:** откройте адрес в Safari → меню «Файл» → «Добавить в Dock».

## Напоминание каждый день
Приложение «Команды» → Автоматизация → «+» → «Время суток» (например, 19:00, ежедневно) → «Запускать сразу» → действие «Открыть URL» с адресом приложения. На Mac — то же в «Командах» (macOS 15 и новее).

## Новые задания
Claude кладёт новый пакет в `packs/` и дописывает его в `packs/index.json`. В приложении он появится при запуске или по кнопке Настройки → «Проверить новые задания».
